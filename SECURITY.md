# Security policy

Lumeleaf is experimental and primarily intended for personal use. Do not rely on it as a security boundary.

Report suspected vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting feature. Please include affected versions, reproduction steps, impact, and any suggested mitigation. Do not include sensitive source files.

Untrusted workspaces must not launch language servers, build tools, hooks, external links, or remote Markdown resources. Security regressions in those boundaries are treated as high priority.
