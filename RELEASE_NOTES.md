# Lumeleaf 1.0.1

This patch release fixes the missing in-app open workflow from 1.0.0.

- Adds working **Open File** and **Open Project** controls to the native window.
- Adds a path field with automatic file/directory detection on Enter.
- Adds asynchronous project discovery and a clickable project sidebar.
- Adds virtualized, line-numbered document rendering.
- Opens a file or directory supplied on the command line.
- Adds `Ctrl/⌘ O` to focus the path field.
- Keeps Java analysis self-contained; no JDK or external language server is required.

Downloads:

- macOS Apple Silicon: `Lumeleaf-1.0.1-macos-arm64.dmg`
- macOS Intel: `Lumeleaf-1.0.1-macos-amd64.dmg`
- Debian/Ubuntu x86-64: `lumeleaf_1.0.1_amd64.deb`
- Portable Linux x86-64: `lumeleaf-1.0.1-linux-amd64.tar.gz`

The macOS applications are ad-hoc signed but not Apple-notarized. On first launch, macOS may require confirmation in Privacy & Security.
