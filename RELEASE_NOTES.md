# Lumeleaf 1.0.0

Lumeleaf 1.0 is the first stable release of the fast, native, view-first Java and Markdown workspace.

Highlights:

- Native, local-only Linux and macOS application with no browser engine, cloud account, telemetry, JRE, or external language server.
- Embedded Tree-sitter Java highlighting, symbols, folds, and error-tolerant parsing.
- Native Git-flavored Markdown reading with safe local-resource rules.
- Dark, light, and sepia themes.
- Memory-mapped large-file reading, fast workspace discovery, Quick Open ranking, repository search, and Git review foundations.
- Deterministic visual tests, race tests, fuzz targets, vulnerability scanning, and enforced performance budgets.

Downloads:

- macOS Apple Silicon: `Lumeleaf-1.0.0-macos-arm64.dmg`
- macOS Intel: `Lumeleaf-1.0.0-macos-amd64.dmg`
- Debian/Ubuntu x86-64: `lumeleaf_1.0.0_amd64.deb`
- Portable Linux x86-64: `lumeleaf-1.0.0-linux-amd64.tar.gz`
- Raw, versioned binaries are provided for every supported architecture.

The macOS applications are ad-hoc signed but not Apple-notarized. On first launch, macOS may require confirmation in Privacy & Security.
